# 电商背景生成系统

## 项目简介

这是一个为电商产品生成背景描述prompt的系统，旨在帮助用户快速生成适合不同产品类型的专业电商摄影背景描述。

## 系统功能

- 支持多种产品类型：服装、电子产品、食品、美妆、家具、配饰、玩具、书籍
- 提供多种背景风格选择：简约、自然、都市、奢华、科技感、节日
- 支持不同构图方式：中心、对角线、三分法、平铺、特写
- 提供多种光线效果：自然光、棚拍、侧光、背光、柔光
- 支持不同颜色方案：中性、暖色调、冷色调、单色调、对比色
- 生成专业的电商产品摄影描述
- 保存生成的prompt到文件

## 系统结构

- `prompt_generator.py` - 核心的prompt生成器类，负责根据参数生成prompt
- `ecommerce_background_generator.py` - 带有用户交互界面的完整系统
- `generated_prompts.txt` - 保存生成的prompt的文件（系统运行后自动生成）

## 如何使用

1. 确保安装了Python 3.x
2. 在命令行中进入项目目录
3. 运行主系统文件：

```bash
python ecommerce_background_generator.py
```

4. 根据提示选择产品类型、背景类型、构图方式、光线类型和颜色方案
5. 系统会生成对应的prompt
6. 可以选择保存生成的prompt到文件
7. 可以选择继续生成其他prompt

## 扩展系统

如果需要扩展系统功能，可以修改 `prompt_generator.py` 文件：

- 添加新的产品类型：在 `product_types` 字典中添加新的键值对
- 添加新的背景选项：在 `background_options` 字典中添加新的键值对
- 添加新的构图方式：在 `composition_options` 字典中添加新的键值对
- 添加新的光线类型：在 `lighting_options` 字典中添加新的键值对
- 添加新的颜色方案：在 `color_scheme_options` 字典中添加新的键值对
- 修改基础模板：修改 `base_template` 变量

## 注意事项

- 本系统生成的prompt适用于文本到图像的AI模型，如DALL-E、Midjourney等
- 生成的prompt可能需要根据具体的AI模型进行调整
- 不同的AI模型对prompt的理解可能有所不同，建议根据实际效果调整参数
